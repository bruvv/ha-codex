# Codex Habitat

OpenAI Codex in your Home Assistant sidebar, with a persistent terminal and
read/write access to your configuration. Review YAML, dashboards, automations,
scripts, packages, and custom components without leaving Home Assistant.

**Back up Home Assistant before approving edits.** This is a coding workspace,
not a replacement for Assist or an unattended administrator.

After installing, start the add-on, select **Show in sidebar**, and open it.
Choose **Sign in with Device Code** to sign in from another device.

Open the **Documentation** tab for [setup, settings, and troubleshooting](DOCS.md).
See the [changelog](CHANGELOG.md) for release notes.
